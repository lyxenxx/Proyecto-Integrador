# Configuración

En esta carpeta se guardan los comandos y archivos utilizados para realizar la configuración y las pruebas del Proyecto Integrador. La información está separada por sistema operativo para identificar con mayor facilidad qué procedimientos se ejecutaron en cada servidor.

Los archivos de esta carpeta sirven como referencia de la configuración realizada durante la práctica. Se incluyen comandos relacionados con la red, conectividad, tabla ARP y Firewall, junto con una explicación breve de la función que cumple cada comando dentro del laboratorio.
