# Capturas

En esta carpeta se almacenan las capturas de pantalla obtenidas durante el desarrollo del Proyecto Integrador. Las imágenes corresponden a los diferentes procedimientos realizados en las máquinas virtuales de **Windows Server** y **Ubuntu Server**.

Se incluyen evidencias relacionadas con la configuración de red, asignación y verificación de direcciones IP, pruebas de conectividad mediante `ping`, consulta de la tabla ARP, configuración y comprobación del Firewall, estado de las interfaces de red y otras verificaciones realizadas durante la práctica.

Las capturas muestran los resultados obtenidos directamente desde las herramientas y terminales utilizadas en cada sistema operativo.
